# Twitch Channel Points Collector

**Локальное расширение Chrome на Manifest V3 для сбора доступных Channel Points в открытых вкладках Twitch.**

Расширение отслеживает открытые вкладки, ищет кнопку получения бонуса и сохраняет настройки в браузере. В панели расширения можно включить автозапуск или управлять сбором вручную.

## Быстрый старт

Скачайте репозиторий и следуйте [инструкции по установке](INSTALL.md). В текущей версии PNG иконки находятся в корне, а манифест ожидает их в каталоге `icons/`. Скопируйте четыре готовые иконки в этот каталог перед загрузкой расширения.

После загрузки откройте Twitch, войдите в аккаунт и откройте трансляцию. Состояние сбора можно посмотреть в панели расширения.

## Как это устроено

| Файл | Роль |
| --- | --- |
| [`manifest.json`](manifest.json) | Манифест V3, разрешения и область работы на `www.twitch.tv` |
| [`background.js`](background.js) | Service worker, события вкладок и проверка наличия бонуса |
| [`popup.html`](popup.html), [`popup.js`](popup.js) | Панель управления и настройка автозапуска |

Обнаружение бонуса зависит от разметки Twitch и может перестать работать после обновления сайта. Если бонусы не собираются, проверьте авторизацию, открытую трансляцию и консоль service worker на `chrome://extensions/`.
