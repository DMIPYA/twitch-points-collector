# Установка Twitch Channel Points Collector

## Подготовьте папку проекта

Скачайте исходники через **Code → Download ZIP** и распакуйте архив либо клонируйте репозиторий.

```bash
git clone https://github.com/DMIPYA/twitch-points-collector.git
```

В папке с `manifest.json` создайте каталог `icons` и скопируйте в него готовые файлы `icon16.png`, `icon32.png`, `icon48.png` и `icon128.png` из корня проекта.

## Загрузите расширение

1. Откройте `chrome://extensions/` в Google Chrome.
2. Включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное** и выберите папку с `manifest.json`.
4. Войдите в Twitch и откройте трансляцию. Проверьте состояние сбора в панели расширения.

Если Chrome не загрузил расширение, проверьте путь к иконкам и нажмите **Обновить** на карточке расширения. Для диагностики работы на Twitch откройте консоль service worker с той же карточки.
